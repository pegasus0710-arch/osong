# 힐스테이트 오송역 퍼스트 · 입주민 공동구매 (삼성스토어)

모바일 우선 반응형 제안 페이지. 서버 없이 GitHub Pages 로 동작합니다.

## 파일
- `index.html` — 페이지 전체 (고객 화면 + 숨은 관리자 모드)
- `data.json` — 제품·가격·문구 데이터 (관리자 모드에서 저장하면 이 파일이 바뀜)
- `images/` — 제품 이미지 (`모델명.png`)
- `details.json` — 제품 클릭 시 보이는 상세 정보(삼성닷컴 갤러리 이미지 주소·전체 스펙·상세페이지 링크)

## 배포 (GitHub Pages)
1. GitHub 에서 새 저장소 생성 (예: `osong-gb`, Public)
2. 위 파일을 모두 업로드 (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<계정>.github.io/osong-gb/` 로 접속

## 관리자 모드 (고객 화면엔 버튼 없음)
- 주소 끝에 `#admin` 붙여 접속 → 예: `https://<계정>.github.io/osong-gb/#admin`
- 또는 페이지 맨 아래 `©` 를 빠르게 7번 탭
- 초기 비밀번호: `osong2026` → **페이지 문구 탭에서 바로 변경하세요**

## 가격 입력
- 출고가·공동구매가를 비워두면 화면에 ‘출고가 / 공동구매가’ 글자로 표시
- 숫자를 넣으면 금액 + 할인율(%)로 자동 전환 (할인율 표시는 끌 수 있음)
- 계산기에 %를 넣으면 공동구매가가 채워지며, % 자체는 저장되지 않습니다
- ⚠️ data.json 은 누구나 열람 가능한 공개 파일입니다. 내부 정책 DC율·마진은 넣지 마세요.

## 저장 방식
**자동 (권장)** — 관리자 → 저장 설정에 계정/저장소/브랜치/토큰 입력 후 `저장·배포`.
토큰 만들기: GitHub → Settings → Developer settings → Fine-grained tokens →
Repository access: 이 저장소만 → Permissions: **Contents: Read and write**.
토큰은 입력한 기기 브라우저에만 저장됩니다. 이 설정이 있으면 이미지 업로드도 바로 됩니다.

**수동** — `저장·배포`(토큰 없음) 또는 `data.json 다운로드` → 저장소의 data.json 교체.

## 참고
- 비밀번호는 화면 진입을 막는 용도이고, 실제 데이터 변경 권한은 깃허브 토큰이 쥡니다.
- 제품 사양 문구는 시안용입니다. 제안 전 최신 스펙으로 확인·수정하세요.

## 제품 상세 / 추가 옵션
- 제품 카드를 누르면 상세창이 열립니다 (사진 슬라이드, 전체 스펙, '삼성닷컴 상세페이지' 버튼).
- 상세페이지 주소는 관리자 → 제품별 '상세페이지 주소'로 바꿀 수 있습니다.
- '추가 옵션 문구/금액' (예: 벽걸이 설치 시 / 금액)을 넣으면 카드에 한 줄 추가됩니다. 금액을 비우면 '+ 00만원'으로 표시됩니다.
